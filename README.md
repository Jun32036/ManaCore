# ManaCore

讓原版生存不再無聊：玩家做的每件事都有意義、有價值。

**目前的主線是單人 Fabric 模組 `ManaCoreMod/`**（Minecraft 26.3）。安裝、玩法與建置見 [`ManaCoreMod/README.md`](ManaCoreMod/README.md)。

以下是先前伺服器插件版本的資料夾，暫時保留作為參考：

| 資料夾 | 內容 |
| --- | --- |
| `ManaCoreMod/` | **單人 Fabric 模組（2.0.0）**：生活手藝、圖鑑、探索、原版成就、城鎮訂單、村民委託、生命祭壇、煉金爐、工程 |
| `ManaCore/` | 主插件（1.5.0）。經濟系統設計見 [`ManaCore/ECONOMY.md`](ManaCore/ECONOMY.md)，建置與指令見 [`ManaCore/README.md`](ManaCore/README.md) |
| `BotBridge/` | 讓玩家用 `/bot` 指揮測試機器人的小插件 |
| `ClaudeBot/` | 測試用機器人（mineflayer） |
| `伺服器工具包/` | 一鍵開啟 26.3 測試伺服器（自動下載 Java 25 與 DivineMC 26.3，內附 ManaCore 1.5.0）。用法見 [`伺服器工具包/README.md`](伺服器工具包/README.md) |
| `模擬工具/` | 30 人模擬（`sim.js`、`analyze.py`）與 1.3.0 經濟試算（`economy_model.py`） |
