# ManaCore

「生生不息」Minecraft 伺服器（DivineMC / Paper 26.3）的 mana 核心插件與相關工具。

| 資料夾 | 內容 |
| --- | --- |
| `ManaCore/` | 主插件（1.3.0）。經濟系統設計見 [`ManaCore/ECONOMY.md`](ManaCore/ECONOMY.md)，建置與指令見 [`ManaCore/README.md`](ManaCore/README.md) |
| `BotBridge/` | 讓玩家用 `/bot` 指揮測試機器人的小插件 |
| `ClaudeBot/` | 測試用機器人（mineflayer） |
| `模擬工具/` | 30 人模擬（`sim.js`、`analyze.py`）與 1.3.0 經濟試算（`economy_model.py`） |
