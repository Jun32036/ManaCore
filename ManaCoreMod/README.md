# ManaCore（單人 Fabric 模組）

讓原版生存不再無聊：採集、種植、畜牧、釣魚、烹飪、建造、探索，**每件事都有一點意義、有一點價值**。

- Minecraft 26.3 · Fabric Loader 0.20.1 以上 · Fabric API · Java 25
- 單人遊戲直接用；也可以放在 Fabric 伺服器上（遊戲邏輯都在伺服器端，客戶端只負責選單畫面）

## 安裝

1. 安裝 Fabric Loader（26.3）與 Fabric API
2. 把 `manacore-2.0.0.jar` 放進 `.minecraft/mods/`
3. 進入世界，按 **M** 開選單（可在「按鍵設定 → ManaCore」改鍵），或打 `/mana`

## 玩法

mana 是這個模組唯一的貨幣。它不是刷出來的，是「做了有意義的事」換來的。

| 來源 | 怎麼拿 | 每天上限（遊戲內一天） |
| --- | --- | --- |
| 生活手藝 | 挖礦砍樹、收成成熟作物、繁殖馴服、釣魚、烤食物做料理、蓋房子 | 共 12，每種手藝 5 |
| 圖鑑 | 第一次挖到、種出、釣到、做出、繁殖某樣東西 | 15 |
| 探索 | 第一次到某個生態域（3）、結構（5） | 15 |
| 原版成就 | 一般 5、目標 15、挑戰 40（每個一次） | 不限 |
| 城鎮訂單 | 每天 4 張，交指定物品 | 24 |
| 村民委託 | 附近村民偶爾會發光，蹲下右鍵他交貨（3 天內有效） | 12 |
| 工程完工 | 自己的建設目標完工獎勵 | 不限 |

**為什麼刷不起來：**

- **新鮮度**：同一種手藝一直做，效率會掉（最低 25%），休息或做別的事會慢慢恢復。
- **多樣性**：最近做的東西種類越多，倍率越高。挖同一種礦一百次不如五種礦各挖幾次。
- **每日上限**：上限到了只累積手藝經驗，不再給 mana。
- **拆掉剛放的方塊**會收回建造點數；**自己放的礦石、原木**打掉不算採集；**創造模式**不算。

**手藝等級與被動**：每種手藝都有等級（Lv1～10），等級越高被動越強——採集、種植有機率多掉一份，釣魚多釣一份，畜牧生雙胞胎，烹飪多做一份，建造等級讓祭壇的建材變便宜。

## mana 用在哪

- **生命祭壇**：一組一組換物資（石材、木材、混凝土陶土羊毛、玻璃光源銅、農作食物、工具功能方塊、特別物品）。
- **工程**：瞭望塔、豐收農莊、港口與燈塔、大圖書館。交物資、投入 mana，完工拿獎勵。
- **煉金爐（等價交換）**：物品投入變成煉金值（損耗 10%），再換成學會的其他物品。不產生 mana，用來把多餘的東西換成需要的東西。物品價值由內建基礎價值加上配方自動推算。

## 選單

按 M 打開，分成：總覽、手藝、委託（城鎮訂單＋村民委託）、祭壇、煉金、工程、圖鑑。獲得 mana 時在畫面下方動作列顯示一行提示。

沒裝客戶端（例如只裝在伺服器）時可以用 `/mana status` 在聊天欄看進度。

## 設定

第一次啟動會產生 `config/manacore.json`（內容與 `src/main/resources/manacore-defaults.json` 相同）。第一層的區塊（例如 `dayCaps`、`altar`、`projects`）你有寫的就整塊取代內建值，沒寫的沿用內建值。

進度存在世界資料夾的 `manacore.json`。

## 建置

```bash
./gradlew build
```

產出 `build/libs/manacore-2.0.0.jar`。需要 Java 25。

- `tools/gen_defaults.py`：從舊插件的 `config.yml` 產生 `manacore-defaults.json`（只在需要重新產生時用）。
- `src/test`：純計算（新鮮度、多樣性、等級、訂單抽選、價值推算）的單元測試，`./gradlew test`。
- `src/gametest`：遊戲內測試，`./gradlew runGameTest`。開一個測試伺服器，用假玩家實際挖礦、收成、放方塊、合成、繁殖、馴服、拿成就、交訂單、交村民委託、在祭壇換東西、用煉金爐、蓋工程，確認 mana、經驗、圖鑑、每日上限都照規則走。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `ManaCore.java` | 進入點：事件、指令、存檔、原版成就 |
| `Mana.java` | mana 的產生與花費、手藝等級、新鮮度、圖鑑、探索 |
| `Hooks.java` | 遊戲事件 → 手藝與圖鑑 |
| `Features.java` | 城鎮訂單、村民委託、祭壇、煉金爐、工程 |
| `Net.java` | 伺服器 ↔ 選單畫面的資料 |
| `mixin/` | 掛在原版的繁殖、釣魚、馴服、成就、合成、放置方塊上 |
| `client/` | 按鍵與選單畫面 |
